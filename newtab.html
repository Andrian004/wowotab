Search Bar // Hidden Capabilities

Search is not just search.

The search bar can do more than simply search the web. Certain commands can control parts of this New Tab environment.

01 — Search

Enter a normal phrase and the New Tab will perform a regular web search.

javascript tutorial

02 — Commands

Commands begin with a forward slash.

/config Open configuration mode.

You can create your own commands by executing these commands:

cmd ls <name> List all existing commands.
cmd add -n <name> -u <url> Add a new command.
cmd remove -n <name> Remove an existing command.

03 — Configuration

Type the following into the search bar:

/config

Configuration options will become available directly inside the New Tab interface.

04 — Clear Search Bar

Type the following into the search bar:

clear

You can use the 'cls' instead of 'clear'.

05 — Emergency Repair

Somehow you managed to break the entire interface. Don't worry. This button restores the New Tab interface to its original state.
